# SmartTray — Siempre un paso antes.

Sitio de producto con la identidad visual de SmartTray: negro, violeta y dorado. Presentación minimalista, tipografía de sistema y componentes Bootstrap 5.3.8.

## Ver la página

Abre esta carpeta en Visual Studio Code. Haz clic derecho en index.html > Reveal in Finder y abre index.html con Safari o Chrome. También puedes usar Live Server si ya lo tienes instalado.

No requiere npm ni compilación. Bootstrap, el logo y las imágenes se incluyen localmente.

## Editar

- index.html: contenido, navegación, secciones y preguntas.
- style.css: colores, tipografía, tamaños y diseño adaptable.
- app.js: demostración interactiva, rutinas y sonido.
- assets/smarttray-logo.png: logo original de SmartTray.
- assets/smarttray-product.png: visualización conceptual del producto.
- vendor/: Bootstrap y su licencia MIT.

## Comprobar la demostración

Selecciona Trabajo, retira las llaves y pulsa “Voy a salir · revisar”. Aparecerá el aviso de objeto faltante. Coloca las llaves otra vez para ver “Todo listo para salir”. Prueba las rutinas Clases y Salida casual, la personalización y el sonido opcional.

La experiencia interactiva es ilustrativa y no se conecta a sensores físicos. No hay compras ni recopilación de datos. La disponibilidad y especificaciones finales se comunicarán con el lanzamiento del producto.
