CONOCE MÁS

Todo claro.
Desde el inicio.

SmartTray es una charola inteligente para colocar objetos de uso diario, identificar cuáles están y avisarte si falta algo importante antes de salir de casa.

Puedes definir tus esenciales para cada ocasión, como llaves, cartera, audífonos o credencial. Los objetos compatibles se detallarán con el lanzamiento del producto.

SmartTray contempla alertas de luz o sonido y una indicación sencilla del objeto faltante. Puedes explorar la experiencia en la demostración de esta página.

Estamos desarrollando SmartTray. La disponibilidad, el precio y las especificaciones finales se anunciarán próximamente.
